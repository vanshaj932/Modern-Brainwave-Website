# 🧠 Brainwave AI Website

🚀 A high-performance AI-powered website built with **React, TailwindCSS, and ESLint**.

## 🛠 Tech Stack

- **JavaScript, React, TailwindCSS** – for frontend development.
- **ESLint** – for maintaining high code quality.
- **VS Code** – Development environment.

## ✨ Features

### 🎨 Frontend
- Developed a **modular component library** with **95% reusability rate**.
- Reduced development time by **60%** through efficient component structuring.

### ⚡ Performance
- Implemented **lazy loading**, achieving **25% faster load times**.
- Ensured **smooth 60 FPS animations** for a seamless user experience.

### ✅ Quality
- Maintained **98% code quality score** through **automated testing** and **ESLint configurations**.

## 🚀 Setup & Installation
```bash
# Clone the repository
git clone https://github.com/yourusername/brainwave-ai-website.git

# Navigate to project directory
cd brainwave-ai-website

# Install dependencies
yarn install  # or npm install

# Start development server
yarn dev  # or npm run dev
```
